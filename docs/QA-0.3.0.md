## 自动化与包

`npm run check` 包含类型检查、**27 个 Node 测试**、宿主 ESM／前端构建、npm 包白名单与素材 SHA-256 核对。无运行时 npm 依赖、安装编译脚本、旧未许可资源或本机数据。CI 使用同一流程并打包 tgz。

新增覆盖：v2 原字节备份、导入角色和旧渐变迁移、幂等及损坏保护；轮廓颜色／缩放参数、两套吸附配置与边缘锚点；同身份临时失败缓存、身份未知／变化／认证失败清空、缓存不记账；原子音效领取、重启／重复领取、静音／取消及通知清理后仍去重；组音效完整顺序、独立真实阶段、取消和停止；问题内容 ID／无 ID 结果、授权取消、新轮开始及重放；随机条目样式、图片大小、整行与库插入约束；费用占比区间、未知费用与来源／作用域／币种隔离、双名搜索、北京时间 30 日及五种峰谷样式。

回归覆盖：不同账户／币种／赠金／零值／充值／跨日；并发、多调用、混合来源、隐藏来源、事件序号、未知模型、推理 token；低余额／预算、校正公式／原记录／撤销／刷新冲突；先归档再移除、90 天／两万条／365 天、归档失败保留与完整检索；生产 HTTP 信任、MIME／路径、资源删除、导入后自动选用、旧通知关闭接口及禁用注销。

## 隔离界面自动操作

`node tools/preview.mjs` 使用临时目录、模拟账户 CNY 与 Key USD，通过生产宿主路由／会话监听器回放，不发外部 HTTP 或模型调用。Playwright 使用普通点击、输入、拖动、键盘和文件选择器；读取 DOM／响应作验证。峰→谷使用受控 `/state` 响应，检查既有节点仍连接，没有靠重建节点切时段。

## 实际 DSH 桌面

使用插件管理器的本机 tgz 地址安装，启用并重启加载。未更改真实 Key、登出真实账号或发起模型请求。

- 两个官方来源均可独立读取，真实余额不同；未把金额或凭据记入仓库。
- 默认白色与自定义粉色 alpha 轮廓；按压父层观察到约 `scale(1.08,0.86)`，轮廓仍为 104%；焦点可见、左右镜像文字正向。
- 原生 0.6/1/1.5/2/2.5 倍分别为 180/300/450/600/750px 挂件；右／下边距 8px。拖到左侧保存 `left/bottom` 锚点；实际窗口 1280×820 放大至 1512×944 后保留原底边距，随后还原。
- 吸附左边界从 35px 拖为 128px；另设 8%，切回 px 仍是 128，两套分别保留。
- PNG 旋转／翻转裁剪保存并自动选用；GIF／APNG 原字节导入，读取到当前帧透明区域 10–40 与 60–90 交替，图像、蒙版和点击区域共用当前帧。
- 原生 WAV 导入、0.5–1.5 秒片段试听／停止／命名保存；音频播放链路验证，未录音核验扬声器。
- 原生气泡排版与余额／今日模板编辑保存；账本近 30 日显示两本 CNY 图表共 60 柱。
- 本机 v1/v2 备份存在。交付包安装、重启及颜色／镜像持久化通过；禁用后挂件、面板、清理入口均移除，宿主接口返回 404。重新启用并重启后正常加载。结束后恢复原有设置／气泡，删除本轮四项测试素材；再次重启确认配置与资源列表均匹配验收前记录。
