# 0.2.0 历史验收记录

本页仅记录当时执行的检查；新增 0.3 功能与明确的验证级别见 [QA-0.3.0.md](QA-0.3.0.md) 和 [逐项对照](UPSTREAM-PARITY.md)。

## 自动化

`npm run check`：TypeScript 类型检查、18 个 Node 测试、宿主 ESM／前端构建、npm 文件审计。

- 双来源不同账户、不同币种、赠金、零余额、充值、北京时间跨日；定点金额、科学计数法、舍入。
- 凭据引用、代理排除、凭据更换、模式持久化、单侧失败、隐藏来源统计；并发、混合来源、序号去重、未知模型、推理 token。
- 队列、A/B 权重、随机候选排除、六行／六模块／图片独占、拆分合并与行内移动；草稿克隆和配置版本冲突。
- 提问／授权优先级、其他提醒排队、去重与解决恢复；生产宿主事件监听器回放。
- 具体账本低余额／预算、跨日重新提醒；校正公式、原观测、撤销、后续下降、刷新冲突和单侧失败。
- v1 原字节备份、迁移幂等、损坏保护；90 天／两万条／365 天归档、失败保留、去重及全部检索。
- 本机素材格式头、MIME、宿主生成 ID／路径、导入／置顶／删除、音效组引用清理；真实 HTTP 授权、Unicode 请求、资源读取、筛选与接口注销。
- npm 入口、bundle patch、七张 PNG、四个 OGG、许可／提示词、SHA-256 清单、旧资源／凭据／本机数据排除。

PNG 透明像素检查沿用 0.1.0 的结果，素材字节未改变。CI 使用相同检查。

## 复现

```sh
npm ci
npm run check
npm audit --omit=dev
npm pack
node tools/preview.mjs
```

最后一条命令用隔离临时目录启动本机 UI 验收页，使用生产路由和监听器，余额／调用为模拟，不发外部请求；退出清理临时目录。生产入口仅允许官方桌面页面。

`node tools/native-visual-compare.mjs` 生成临时 `0.2.0-visual-check` 对照包，不用于交付或发布；截图后必须重新安装正常 0.2.0 并重启。

## 验证边界

未额外发起付费对话、登出真实账号、修改 Key、充值或校正真实账本。完成／提问／授权及费用归属用宿主事件回放，真实模型流量仍需日常使用验证。余额观测不是完整账单，估算区间不能替代平台账单。

Web 不支持；Windows／Linux 未实测；新年份节假日需更新宿主日历。正式 npm 名称安装等待另行确认发布后验证。
