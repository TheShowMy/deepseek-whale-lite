# 验收记录

日期：2026-10-10。环境：官方 DSH 桌面端 **0.2.0-rc.2 / macOS arm64**，安装入口为桌面插件管理器，本地 `.tgz`。

## 自动化通过

`npm run check`：TypeScript 类型检查、9 个 Node 测试、宿主 ESM／前端构建及 npm 文件审计通过。`npm audit --omit=dev`：0 个漏洞。

- 不同账户、不同币种、赠金钱包、零余额、充值增加与跨日基线。
- 官方账号钱包的科学计数法、超过 8 位小数及负余额；整数解析和精度舍入。
- 自定义凭据引用、第三方代理过滤、Key 失效、查询期间更换凭据。
- 双余额模式持久化、单侧失败、隐藏来源继续记账。
- 并发 session、同轮混合来源、重复与已结算事件、未知模型、推理 token 不重复计算。
- TypeScript 类型检查、双端构建、npm 内容白名单与旧资源排除。
- 真实 Node HTTP 路由的宿主身份校验、方法、设置参数校验及路由注销；早期注入及重复注入保护。
- npm 包入口、bundle patch、七张 PNG、四个 OGG、许可及生成提示词完整；素材 SHA-256 与清单一致。

七张 PNG 均为 RGBA，透明像素检查通过。CI 与本地使用同一组检查。
